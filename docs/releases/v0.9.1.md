# v0.9.1 — Dependency Security Patch

**Released:** 2026-11-02
**Sprint:** none (out-of-band maintenance patch)
**Theme:** Close dependency CVEs reported by the 2026-11-02 pip-audit sweep.

## Summary

Dependency-only release. No source, CLI, or public API changes. pip-audit
over the full lock (all extras and dependency groups) reported 24 advisories
across 11 packages. Ten packages are upgraded to the minimum fixed version or
later; four pyasn1 GHSAs are deferred for supply-chain quarantine. See
`CHANGELOG.md` 0.9.1 for the per-package advisory list.

- **pyasn1 0.6.5** closes GHSA-2qm8-x737-gmw5, GHSA-fm9c-5rcf-2q5p,
  GHSA-mm57-4v3p-rchx, and GHSA-9m75-vc3g-4x39. It was published 2026-10-27
  and stays inside the 7-day quarantine until 2026-11-03. Exposure is limited
