# v0.9.2 — Release Pipeline Fix

**Released:** 2026-11-02
**Sprint:** none (out-of-band maintenance patch)

## Summary

The v0.9.1 tag was pushed, but the release workflow failed at `twine check`.
Both hatchling 1.32.4 and 1.33.0 emit Metadata-Version 2.5, and twine 6.2.0
rejects that version. Nothing was published to PyPI for v0.9.1, and no GitHub
Release was created. v0.9.2 ships the v0.9.1 dependency security fixes (see
`docs/releases/v0.9.1.md`) and upgrades the publish-only twine dependency to
7.0.0.

## Dependency changes

| Package | Old | New | Scope | Major bump |
|---------|-----|-----|-------|------------|
| twine | 6.2.0 | 7.0.0 | publish | yes |
| packaging | 26.0 | 26.3 | transitive | no |

Both versions are past the 7-day quarantine. twine is Apache-2.0.
